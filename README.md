# ThreatLens AI

## AI-Powered Email Threat Detection, GeoLocation and Forensic Intelligence Platform

ThreatLens AI is a full-stack cybersecurity platform designed to analyze suspicious emails, identify phishing indicators, calculate threat risk, extract IOCs and support forensic investigation.

## Features

- AI Email Threat Detection
- Phishing Risk Scoring
- Suspicious Indicator Detection
- IOC Extraction
- Forensic Intelligence
- GeoLocation Intelligence Workspace
- Investigation History
- Cybersecurity Dashboard

## Technology Stack

- FastAPI
